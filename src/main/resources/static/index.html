Mật khẩu mã hóa cơ sở dữ liệu

Mật khẩu nhập ở màn hình mở khóa khi khởi động ứng dụng. Quên mật khẩu này sẽ không khôi phục được dữ liệu.

Hướng dẫn sử dụng & Trợ giúp

1. Ba khu vực làm việc cốt lõi

  • Thẩm định Excel: Kéo thả hoặc chọn file Excel của đơn vị để tự động chuẩn hóa cấu trúc về Biểu mẫu 26.9, đối soát công thức NĐ 178 & NĐ 177, xuất báo cáo và lưu vào hồ sơ.
  • Hồ sơ: Quản lý cơ sở dữ liệu hồ sơ theo cây đơn vị 4 cấp (Quân khu / Bộ tư lệnh → Sư đoàn / Cục → Trung đoàn → Tiểu đoàn). Tìm kiếm, lọc theo phụ lục, trạng thái và xuất danh sách.
  • So sánh: Nạp file Lần 1 để lưu làm mốc, nạp file Lần 2 (bản đơn vị gửi lại) để hệ thống tự liệt kê người thêm mới, bị loại và các thông tin, số tiền đã thay đổi; xuất được ra Excel.
  • Tính thủ công: Tra cứu và tính toán nhanh từng trường hợp quân nhân nghỉ hưu hoặc thôi việc theo Phụ lục I.1, I.2, I.3.

2. Biểu mẫu chuẩn & Tải file mẫu

Hệ thống hỗ trợ tự động chuẩn hóa và đọc mọi cấu trúc file từ Quân khu, Quân đoàn, Binh chủng về Biểu mẫu 26.9 chuẩn.

3. Phím tắt & Thao tác nhanh

  • Esc: Đóng nhanh mọi hộp thoại / chi tiết đang mở.
  • Enter / Space: Kích hoạt vùng chọn file Excel hoặc nút thao tác.
